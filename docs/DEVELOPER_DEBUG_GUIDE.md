# راهنمای جامع دیباگ همزمان فرانت‌اند و بک‌اند تنظیم (Full Stack Debugging Guide)

این راهنما روش‌های دیباگ سریع، گذاشتن Breakpoint روی کدهای React/TypeScript و کدهای پایتون FastAPI، و اجرای یکپارچه فرانت و بک را توضیح می‌دهد.

---

## ۱. دیباگ با یک کلیک در VS Code (پیشنهادی 🚀)

پوشه `.vscode/` از قبل برای پروژه تنظیم شده است. برای دیباگ:

1. پروژه را در **VS Code** باز کنید.
2. کلید `F5` را بزنید (یا به تب **Run and Debug** با میانبر `Ctrl+Shift+D` بروید).
3. از منوی کشویی بالا یکی از گزینه‌ها را انتخاب کنید:
   - **`Full Stack: Chrome + FastAPI`**: اجرای همزمان بک‌اند پایتون و باز شدن مرورگر کروم متصل به دیباگر.
   - **`Full Stack: Edge + FastAPI`**: اجرای همزمان بک‌اند پایتون و مرورگر اج.
   - **`Backend: FastAPI (debugpy)`**: اجرای اختصاصی بک‌اند با قابلیت توقف روی Breakpoint در کدهای پایتون.
   - **`Frontend: Chrome (Vite)`**: دیباگ اختصاصی فرانت‌اند با نقشه سورس (Sourcemap).

> **گذاشتن Breakpoint:**
> کافی است در فایل‌های `.tsx` یا `.py` کنار شماره خط کلیک کنید تا نقطه قرمز ظاهر شود. با ارسال درخواست، اجرای برنامه در همان خط متوقف شده و مقدار متغیرها در پنل Variables قابل مشاهده است.

## ۲. دستورات اجرای سریع در ترمینال (NPM Scripts)

اگر نمی‌خواهید از تب Run and Debug استفاده کنید، دستورات زیر در `package.json` اضافه شده‌اند:

```bash
# اجرای همزمان فرانت‌اند و بک‌اند با لاگ‌های رنگی مجزا و مدیریت خروج:
npm run dev:all

# فقط اجرای بک‌اند با ریلود خودکار:
npm run dev:backend

# اجرای بک‌اند با پورت دیباگ ۵۶۷۸ (برای اتصال دستی دیباگر):
npm run dev:backend:debug

# فقط اجرای فرانت‌اند:
npm run dev
# یا:
npm run dev:frontend
```

---

## ۳. اجرای با یک دابل‌کلیک در ویندوز (بدون نیاز به باز کردن ترمینال)

در پوشه `scripts/`:
- **`scripts/dev.bat`**: دابل کلیک کنید تا فرانت‌اند (`http://localhost:5173`) و بک‌اند (`http://127.0.0.1:8000`) همزمان بالا بیایند.
- **`scripts/debug-backend.bat`**: بک‌اند را روی پورت ۵۶۷۸ برای debugpy باز می‌کند.

## ۴. آدرس‌ها و دسترسی‌های محلی

| سرویس | آدرس محلی | توضیحات |
| :--- | :--- | :--- |
| **فرانت‌اند (Vite PWA)** | `http://localhost:5173` | بارگذاری سریع با HMR و پروکسی خودکار `/api` |
| **مستندات تعاملی بک‌اند (Swagger)** | `http://127.0.0.1:8000/docs` | تست زنده تمام روت‌های API |
| **مستندات ریداک (Redoc)** | `http://127.0.0.1:8000/redoc` | مستندات تمیز ساختار داده‌ها |
| **سلامت سرویس** | `http://127.0.0.1:8000/api/health` | بررسی وضعیت دیتابیس و نسخه اسکیم |

## ۵. نحوه عملکرد پروکسی Vite (`/api`)

در `vite.config.ts` پروکسی زیر فعال شده است:
```ts
proxy: {
  "/api": {
    target: "http://127.0.0.1:8000",
    changeOrigin: true,
  }
}
```
این یعنی هر درخواستی در فرانت‌اند به `/api/...` ارسال شود، بدون خطای CORS مستقیماً به سرور محلی FastAPI در پورت ۸۰۰۰ فرستاده می‌شود.

## ۶. تنظیم دیتابیس محلی (SQLite بدون دردسر یا PostgreSQL)

در فایل `backend/.env`:
- **حالت پیش‌فرض (Zero Config):** از دیتابیس سبک SQLite در مسیر `backend/tanzim_dev.db` استفاده می‌شود که با اولین استارت جداول را خودکار می‌سازد و هیچ نیازی به نصب یا اجرای سرور دیتابیس جداگانه ندارد:
  ```env
  DATABASE_URL=sqlite:///./tanzim_dev.db
  ENVIRONMENT=development
  ```
- **حالت PostgreSQL:** اگر روی سیستم خود PostgreSQL دارید، کافی است خط دیتابیس را تغییر دهید:
  ```env
  DATABASE_URL=postgresql+psycopg://tanzim_app:change-me-with-a-long-random-database-password@127.0.0.1:5432/tanzim
  ```
